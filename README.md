# swag-labs-test-cases

## Project Overview
This repository contains a comprehensive set of test cases designed to validate the functionality, usability, and cross-platform compatibility of the **Swag Labs (Saucedemo)** e-commerce website. 
The project focuses on ensuring a seamless user experience by testing critical business flows across different browsers and mobile device simulations.

## Scope of Testing
The testing suite covers 62 detailed test cases across the following core modules:
- **Login Module:** Authentication success/failure, UI validation, and error handling.
- **Product Module:** Product listing, sorting, and detailed view.
- **Cart Management:** Adding/removing items and real-time badge updates.
- **Checkout Process:** multi-step checkout flow (Information, Overview, and Completion).
- **Navigation & Sidebar:** Menu functionality and redirection.

## Test Environment
To ensure a consistent experience for all users, tests were performed on the following environments:
- **Desktop Browsers:** Google Chrome, Microsoft Edge.
- **Mobile Devices:** iPhone Xs Max, Samsung S20.

## Documentation Structure
The test cases are structured in a clear, professional format including:
- **ID:** Unique identifier for each test case.
- **Preconditions:** Required state before execution.
- **Execution Steps:** Step-by-step instructions to perform the test.
- **Test Data:** Specific inputs used during testing (e.g., credentials).
- **Expected vs. Actual Result:** Defined benchmarks for success.
- **Priority:** Severity levels (High/Medium/Low).
- **Status:** Pass/Fail results across different environments.

## How to Use
1. Download the `TESTCASE.xlsx` file.
2. Review the "Sheet1" for the full execution matrix.
3. Use the defined **Test Data** to reproduce cases on [Saucedemo](https://www.saucedemo.com/).
